# Maths Revision

Separate Maths module inside the existing English Practice repository. It is intentionally isolated from the English app.

Planned structure:
- `index.html` – mobile-first Maths UI
- `css/app.css` – responsive styles
- `js/config.js` – Apps Script endpoint
- `js/api.js` – lightweight API client
- `js/quiz.js` – fast local quiz state / pause-resume
- `js/app.js` – Home, Chapters, Library, On Demand and More
- `apps-script/Code.gs` – Google Sheets backend for the `Maths Revision` spreadsheet

The Maths backend uses the Google Sheet `Maths Revision`. English files are not modified.
